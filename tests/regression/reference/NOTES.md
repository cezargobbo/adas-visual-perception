# Reference alerts: notes

`fast/` and `accurate/` hold the alerts CSVs (`<video>_alerts.csv`) and a `summary.txt`
(one line per video: wall time and FCW/LDW/RLR event counts) written by
`tools/regression/make_reference.sh` for each profile, with detection only (`--no-seg`).
`summary.txt` is regenerated by that script, so observations are kept here instead.
The source videos are private and not distributed; the CSVs were produced from them.

## Determinism

Checked on one video only (`red_crop_2_30fps`, fast profile, `--no-seg`): two runs with
different output prefixes gave byte-identical alerts CSVs. Other videos and the accurate
profile were not re-run for this check.

## Differences vs. earlier runs of the same reference script

Compared with CSVs from earlier runs of the same reference script (before the
`red_for_s` column and RLR events were added):

- Fast profile, `sp1_*` videos (FCW/LDW): event times, frames, types, levels and TTC
  values were identical, including `lead_id` and `lead_dist`.
- The only change is the new `red_for_s` CSV column (RLR) and the RLR events, which did
  not exist in those earlier runs.
- RLR, fast profile: `red_crop_8` fires at 7.13 s (earlier 7.17 s) and `red_crop_9` at
  10.50 s (earlier 10.47 s); all other videos match exactly (`red_crop_1` has no event;
  `red_crop_5` fires at 9.13 s and 90.30 s).
- RLR, accurate profile: all 13 red-light videos match the earlier run exactly
  (`red_crop_1` none, c2 7.77, c3 8.73, c4 9.13, c5 9.13 and 90.30, c6 10.77, c7 9.47,
  c8 7.17, c9 10.47, c10 7.83, c11 15.53, c12 15.23, c13 15.53 s).
- FCW/LDW, accurate profile vs. fast-profile-like earlier CSVs: they differ by design.
  - `sp1_crop_30fps`: FCW at 30.63, 88.49 and 127.23 s (earlier 127.96 and 155.36 s);
    the two LDW events (153.25 and 158.46 s) are the same.
  - `sp1_crop_2_30fps`: FCW at 18.39 s, same time (TTC 2.16 vs 2.26).
  - `sp1_crop_3_30fps`: no events, same.
  - `sp1_crop_4_30fps`: the three LDW events are the same; FCW at 34.93, 65.30, 67.23 and
    157.92 s (earlier 34.93, 35.30 critical, 67.23 and 158.26 s).
- An earlier summary line for `sp1_crop_30fps` reported 3 FCW events while its CSV had 2;
  the accurate profile yields 3 (30.63, 88.49, 127.23 s), so that line likely came from
  an accurate-profile run.
